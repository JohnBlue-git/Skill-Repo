# Core

Skills for managing this repo. Install on every machine.

- **[skill-manager](./skill-manager/SKILL.md)**: list sets, recommend ones for this machine, install or uninstall them.
- **[skill-maintainer](./skill-maintainer/SKILL.md)** (`/skill-maintainer`): find stale skills and draft tested refreshes on a `refresh/<date>` branch for you to review.
